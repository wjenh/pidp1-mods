## Include files for DCS2, the Data Communication Syatem

This directory contains two forms of include file.

All ending in *.ah* only contain definitions, no code

All ending in *.ac* incldue code, place them in your code as desired.

## What's here?

- dcs2defs.ah, defines the iots for DCS
- getach.ac, read an ascii character from a channel
- getaln.ac, read an ascii  line from a channel
- getlin.ac, read a line from a channel using its character mode
- textascii.ac, write a line of text produced by the am1 ascii directive to a channel
- textflex.ac, write a line of text produced by the am1 text directive to a channel

See the Docs directory for detailed DCS usage.
