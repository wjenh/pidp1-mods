## Include files for the Type 64 line printer

This directory contains two forms of include file.

All ending in *.ah* only contain definitions, no code

All ending in *.ac* incldue code, place them in your code as desired.

## What's here?

- type64defs.ah, defines the iots for the line printer
- printFlex.ac, send a line of flexo text to the printer
- printAscii.ac, send a line of ascii text to the printer

See the Docs directory for the Type 64 usage.
