# Conflict with the Parallel drum

Both the Type 340 and the Parallel Drum use dra and drs.
If you use both devices, you will have to use the direct iot values for one or the other or
use the t340dra and t340dss alternate IOT name.
The suggested method is to include type340alt.ah which will define t340dra and t340dss instead of dra and dss.
