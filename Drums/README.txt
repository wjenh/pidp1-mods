This directory is the library of drum images that pdp1central's Drums tab lists.
A drum image is a copy of /opt/pidp1-mods/pdp23drum named with the .drm extension.
Save drum on the Drums tab copies the drum here.
Pick copies a chosen image onto pdp23drum, copying the current drum to pdp23drum.bak first.

An optional index.txt here lists images and folders kept elsewhere, one path per line.
A relative line is relative to this directory.
Lines starting with # are comments.
The Drums tab's Add file..., Add folder... and Delete entry update this file.
