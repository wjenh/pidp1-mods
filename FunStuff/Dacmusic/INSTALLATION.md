# Installing the Dacmusic components

Installation is easy, two steps.

## The IOTs

The IOT code has already been installed, but you need to build it.

In /opt/pidp1-mods/IOTs/DAC, type 'make install'.
That's it.
If the PDP-1 is running, no need to restart it, the IOTs will automatically load the first time they're used.

## The programs

In this directory, /opt/pidp1-mods/FunStuff/Dacmusic, type 'make'.
Again, that's it.

## Next?

Read the documents here. Really. Otherwise, you won't have a clue how to use everything here.

*Please* don't play back through the pathetic little speakers the full pidp-1 has, they will reproduce
sound about as well as, umm, nothing worth listening to.
Easiest is to use some good PC speakers, plug the audio jack into the USB dongle.
And, that dongle is pretty lame also. A better quality one is cheap, Amazon has plenty.
I use a *UGREEN USB to 3.5mm Jack Audio Adapter Headphone DAC 24bit 96kHz*, works great.
