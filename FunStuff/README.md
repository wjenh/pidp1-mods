## PDP-1 example programs

These directories contain various programs written in am1 assembler.\
Each directory has a makefile, just type make in one.

## What programs are there?

- Pong contains the pong game converted from the original macro to am1
- Rotator contains a program that will cycle through up to 6 programs, one per minute, from the drum
- Switcher contains a program that will listen for a telnet connection and ask for a program to run
- Demos contains a collection of various demonsrations of some of the added IOTs

## What's in Demos?

- symgen, cg200chars, cgdemo, and cfgast demonstrate the Type 33 Symbol Generator
- lightpen, demonstrates the light pen, use with the p7sim or Ian S's display only
- drawLines, a semi-recreation of the original lightpen line drawing program
- programSelector, allows picking and running a program from the drum using the light pen
- findAndTrack, another light pen demo that lets you move a cross around the screen
