This is an implementation of an interface to a Chrono Log 2100 series time-of-day clock.
While this was never sold by DEC, it was a field hack.
Chrono Log actively marketed the clock for PDP's, there's every reason to believe
an IOT for it was implemented somewhere.
In tribute to that early hardware hacker culture, here's one.

It uses the Linux time, just pretend there's a 2100 connected.

See the documentation in Docs for use details.
