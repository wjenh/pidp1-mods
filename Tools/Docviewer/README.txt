This directory contains docviewer, a simple utility for converting tape images that are actually text
to readable ascii.

There appears to be a common representation of documentation on a tape that is a mix of readable Flexo characters
and formatting directives.

Annoyingly, these are often called xxx.bin.

This will read such a tape and produce formatted, readable output from it.

Usage: docviewer tapefile

As usual, just type 'make' to build it.
