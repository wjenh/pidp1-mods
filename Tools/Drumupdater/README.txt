Drumupdater is a utility program to load a tape image onto a type 23 drum track.
Drumlist is a utility program to list loaded images on a type 23 drum's tracks:
drumupdater's programs, Adventure's and a Z-machine story's tracks, and, given an am1
.ovl file, its overlays. It compiles in ../Ovlload/ovlfile.c.
By default, the drum image is the file '/opt/pidp1-mods/pdp23drum'.

See the usage in the C files.
